# UX/UI-исследование: CyberQuiz

## 1. Проблема и ценность
- **Человеческий фактор** — около 60% утечек в Verizon DBIR 2025 связаны с участием человека (кража учётных данных, социальная инженерия, ошибки). Вклад третьих сторон в утечки вырос с 15% до 30%.
- Обычное обучение безопасности — это долгие лекции, которые проходят «для галочки». Нужен короткий формат, который реально закрепляет навык.

**Ценностное предложение:** «5 минут в день — и вас сложнее обмануть». Квиз на реальных сценариях с мгновенным разбором.

## 2. Целевая аудитория
| Сегмент | Задача | Что важно в UX |
|---|---|---|
| Сотрудники компаний | Пройти awareness-обучение быстро и с пользой | Короткие сессии, без обязательной регистрации |
| HR / ИБ-отделы | Повысить грамотность сотрудников, видеть прогресс | История результатов, темы, будущие курсы |
| Студенты / новички в IT | Разобраться в базовых атаках | Фильтр сложности, понятные объяснения |
| Обычные пользователи | Защитить себя и семью от мошенников | Простой язык, бытовые сценарии (звонки, SMS) |

## 3. Выводы исследования → решения в продукте
| Вывод | Источник | Решение |
|---|---|---|
| Активное припоминание (retrieval practice) закрепляет знания лучше, чем перечитывание; обратная связь с правильным ответом усиливает эффект | Обзоры по testing effect (Erasmus Univ.; Frontiers in Psychology 2019) | Квиз — основа продукта, после каждого ответа объяснение |
| Немедленная обратная связь лучше отложенной для усвоения фактов | Рецензируемое исследование (PMC8200521), опыт Codecademy | Разбор сразу после ответа, краткий (2–3 предложения) |
| Обратная связь не должна держаться только на цвете | Разборы quiz-UX (screensdesign) + WCAG 1.4.1 | Иконки ✓/✕, текстовые заголовки «Верно!/Не совсем», aria-label |
| Короткие квизы + видимый прогресс удерживают пользователя | Материалы по quiz-funnel и gamification | 5/10/20 вопросов, прогресс-бар, который стартует не с нуля |
| Награды — умеренно, иначе обесцениваются | Uxcel, курс по геймификации | Только итоговый «статус» и разбор по темам, без бейджей за каждый клик |
| Если успешных ответов мало, эффект обучения падает | Исследования reversed testing effect | Фильтр сложности, лёгкие вопросы для новичков, ссылка на блог после низкого результата |
| Запоминание позиции правильного ответа искажает результат | Практика тестирования | Рандомизация порядка вопросов и вариантов, гарантированно отличного от прошлой попытки |

## 4. Принципы интерфейса
1. **Яркие акценты на тёмном градиентном фоне.** Фиолетово-синий градиент + неоновые циан/розовый/лайм — «кибер»-эстетика, но контраст текста ≥ 4.5:1 (светлый текст на тёмном фоне).
2. **Один главный CTA на экран.** «Начать квиз» — градиентная кнопка, всё остальное вторично.
3. **Низкий порог входа.** Квиз без регистрации; аккаунт нужен лишь для истории — предлагаем мягко.
4. **Клавиатура и доступность.** Клавиши 1–4 и Enter, фокус-кольца, skip-link, `aria-live` для вопросов, `prefers-reduced-motion`.
5. **Mobile-first.** Варианты ответов ≥ 56px высотой, бургер-меню на узких экранах.
6. **Карточки со стеклянным эффектом (glassmorphism)** — выделяют контент на градиенте, не перегружая.

## 5. Пользовательский путь
```
Главная (ценность, статистика) ──► Квиз: выбор темы/сложности ──► Вопрос ──► Разбор ──► … ──► Итог по темам
       │                                                                                    │
       └──► Блог (статья) ──► «Квиз по теме» ◄──────────────────────── «Почитать блог» ◄──┘
                                    Регистрация ──► Профиль: история попыток
```

## 6. Метрики успеха
- Доля начавших квиз → завершивших (цель ≥ 70%).
- Повторные попытки в течение 7 дней.
- Рост среднего результата пользователя между попытками.
- Конверсия гость → регистрация после итогового экрана.

## 7. Что проверить на реальных пользователях
- 5 юзабилити-интервью: понятен ли разбор, раздражает ли рандомизация при повторе.
- A/B: немедленный разбор vs. разбор в конце квиза.
- Опрос после квиза (1 вопрос): «Узнали что-то новое?»
