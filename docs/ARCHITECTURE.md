# Архитектура

```
public/                  статический фронтенд: HTML + ES-модули, без сборки
  js/config.js           адрес API, навигация, флаги функций
  js/app.js              api(), шапка/подвал, утилиты
  js/<страница>.js       логика конкретной страницы
data/                    открытый JSON-банк: вопросы, блог, курсы
docs/API.md              контракт, который реализует бэкенд
docs/db/                 схема PostgreSQL
scripts/                 экспорт JSON → PostgreSQL / MongoDB
```

## Бэкенд
Отдельный сервис на Go (в этом репозитории его нет). Фронтенд ничего не знает о реализации — только о контракте из
[API.md](API.md). Вся логика квиза (рандомизация, проверка ответов, подсчёт баллов) и авторизация — на стороне API:
правильные ответы никогда не попадают в браузер.

## Развёртывание
Вариант 1 — один домен: reverse proxy (nginx/Caddy) или сам Go-сервер отдаёт `public/` как статику и проксирует `/api` в API.
Cookie и CORS настраивать не нужно.

Вариант 2 — разные домены: `public/` на любом статическом хостинге/CDN, в `config.js` полный адрес API, на API — CORS с credentials.

Ссылки между страницами ведут на `*.html` (статья — `post.html?slug=…`), поэтому никаких правил переписывания URL на хостинге не требуется.
`404.html` подхватывается большинством хостингов автоматически.

## Перенос банка заданий в БД
- PostgreSQL: `npm run export:sql > dist/seed.sql && psql "$DATABASE_URL" -f dist/seed.sql` (проверено на PostgreSQL 16).
- MongoDB: `npm run export:mongo`, затем `mongoimport` по инструкции в выводе скрипта.

Формат JSON рассчитан на оба варианта: плоские записи со строковыми `id`, ссылки по `category`, варианты ответа вложены
(Mongo — один документ, Postgres — таблица `question_options`).

## Добавление курсов
Уже подготовлено:
- `data/courses.json`: курс → модули → уроки (`article` ссылается на пост блога, `quiz` — на фильтры квиза).
- Страница `public/courses.html`; таблицы `courses / course_modules / lessons / enrollments / lesson_progress` в SQL-схеме;
  эндпоинты `/courses` в [API.md](API.md).
- Включение: `FEATURES.courses = true` в `public/js/config.js` — пункт «Курсы» появится в навигации.

Дальше: страница курса и урока, запись на курс, прогресс (`lesson_progress.attempt_id` связывает урок-квиз с попыткой).

## Когда фронтенд вырастет
Сейчас хватает многостраничного ванильного JS. Если понадобятся сложные интерактивные экраны (личный кабинет курсов, админка) —
переход на React/Next.js или Vue не затронет API: контракт остаётся тем же.
